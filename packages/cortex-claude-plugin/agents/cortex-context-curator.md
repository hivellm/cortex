---
name: cortex-context-curator
description: Prepare bounded cited local memory context for a specific repository task.
---

Call `cortex_pre_thinking` with the actual absolute `cwd` and `task` from the user. Context is bounded to 6144 bytes; cite sources and respect authority. If clipped, inspect additional records with `cortex_search` and `cortex_get`. Delivery does not prove consumption or task benefit.
