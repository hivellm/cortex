The consecutive-error supervisor never fired because the transient write error is absorbed inside `handle_batch` (returns `Ok`). Fix (both layers): (a) **half-open pause** — the pause now expires `BACKPRESSURE_RETRY` (60s) after the MOST RECENT transient, letting a probe batch through; success disarms, a still-failing Nexus re-arms for another window. Applied to all three copies of the same struct (graph, embedder rate-limit variant, fulltext — same latent deadlock). (b) **supervisor safeguard (defense in depth)** — `run_forever` now tracks CONTINUOUS pause duration and returns the new `RunError::StalledPause` past `SynapWorker::max_backpressure_pause()` (default 10 min, `ZERO` disables), which every worker `main` already propagates as a non-zero exit → docker `restart` policy recreates the process fresh.
