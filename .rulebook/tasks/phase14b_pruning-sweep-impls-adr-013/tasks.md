## 3. Cold-tier prune as Sweep
- [x] 3.1 New `impl Sweep for ColdTierPrune`. Default schedule `0 5 * * 0` (weekly Sunday 05:00 UTC). Default cutoff: 365 days. (`COLD_TIER_PRUNE_NAME = "cold_tier_prune"`, `COLD_TIER_PRUNE_SCHEDULE = "0 0 5 * * 1 *"` — the `cron` crate keys day-of-week 1..=7 with Sunday=1, comment pins this constraint, `COLD_TIER_DEFAULT_CUTOFF_DAYS = 365`.)
- [x] 3.2 For each `event_identity` row with `occurred_at < cutoff`, dispatch DELETE to Synap, Nexus, Meili, archive. Vectorizer handled per §4. (run_identity_cascade with `CascadePolicy::COLD` drops Meili+Nexus+per-event Vectorizer+archive partition. Synap purge is intentionally NOT cascaded — Synap's id IS event_id per ADR-012 and Synap is event-stream-only, no per-event delete primitive. The cascade then invokes ADR-013's `reencode_collection(COLD_BINARY_COLLECTION, predicate)` to evict the cold-binary survivors whose `payload.occurred_at_ms < cutoff_ms`.)
- [x] 3.3 Post-cascade assertion: row absent in `event_identity` AND every backend reports Not-Found for the event_id. (cascade-driver ack semantics: on cascade-leg success, `IdentitySource::forget_identity(event_id)` drops the SQLite row; on any leg error the row is preserved so the next sweep retries. Tests assert both branches: the 100-event IT asserts `known_ids` returns exactly the 30 hot survivors post-prune; the failure-path test asserts the failing event_id is still in `known_ids`.)
- [x] 3.4 IT covering 100 events: 30 hot + 70 cold; post-prune asserts cold ones are gone everywhere. (Lands at `retention::cold_tier_prune::tests::cold_tier_prune_handles_100_events_30_hot_70_cold_scenario`. Seeds 30 hot rows (2026-04-01 partitions) + 70 cold rows (2024-01-01 partitions). Asserts: rows_processed=70, every cascade backend (meili/nexus/vector/archive) called exactly 70 times, identity source post-prune holds exactly the 30 hot ids.)

## 4. Vectorizer collection-level re-encode
- [x] 4.1 New `crates/cortex-workers/src/embedder/vectorizer_prune.rs::reencode_collection(name, predicate)` that streams alive vectors out, drops the collection, rebuilds it from the stream. (Function signature `reencode_collection(ops, name, predicate) -> Result<PruneReport, PruneError>`. 5-step pipeline: clear stale .tmp -> page through source -> run predicate per record -> flush survivor batches into .tmp every BATCH_SIZE=64 records -> atomic two-step swap (drop original then rename .tmp over it).)
- [x] 4.2 Predicate is "occurred_at >= cutoff" expressed against the projected payload. (`PrunePredicate = Arc<dyn Fn(&Value) -> bool + Send + Sync>`. ColdTierPrune builds the predicate as `|payload| payload.get("occurred_at_ms").and_then(as_i64).unwrap_or(MAX) >= cutoff_ms` — the unwrap_or(MAX) defaults missing payloads to "keep" so a malformed row never disappears silently.)
- [x] 4.3 Atomicity: re-encoded collection is built under `<name>.tmp`, swapped on completion. Failure leaves the original intact. (TMP_SUFFIX = ".tmp" constant (reserved per ADR-013 #4). Two-step swap: drop original -> rename .tmp over it. Every failure path (list error, upsert error, swap error) invokes `rollback(ops, &tmp_name)` which best-effort drops .tmp; original collection is NEVER touched before the swap step.)
- [x] 4.4 Test against an in-memory Vectorizer fixture with 1k vectors (300 expired): post-prune count == 700 alive. (Lands at `embedder::vectorizer_prune::tests::reencode_drops_expired_and_keeps_survivors`. Seeds 1000 vectors (700 kept=true / 300 kept=false), runs reencode_collection with the kept-true predicate, asserts report.scanned=1000 / kept=700 / dropped=300 / invariant_holds + live collection holds exactly 700 survivors / every survivor carries kept=true payload / .tmp removed post-swap.)
