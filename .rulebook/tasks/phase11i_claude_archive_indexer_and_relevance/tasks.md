## 4. Pre-thinking surfaces + measurement (week 3)

- [x] 4.1 New "Past sessions" section landed in `crates/cortex-pre-thinking/src/formatter.rs` (this crate carries the renderer; the proposal called it `render.rs`). New `cortex_api::PastSession` type ships under `results.past_sessions: Vec<PastSession>` with `session_id` / `ts` / `first_prompt` / `turn_count` / `score`. Renderer pins one line per session: `N. <id> — <YYYY-MM-DD> · "<prompt clipped to 80 bytes>" · <turn_count> turn(s)` and lives between similar_turns and snippets so existing section order stays stable. New caps `PAST_SESSIONS = 3` (top-3 contract) + `PAST_SESSION_PROMPT_BYTES = 80` exposed via `FormatOptions.past_sessions_cap` / `past_session_prompt_byte_cap`. Section is omitted entirely when empty so cold caches degrade silently. Within the existing 32 KiB clipper budget by design — three 80-char lines add ~300 B, the existing trim ladder still owns the dominant sections (snippets / decisions / turns / graph). 6 unit tests pin shape, byte cap, position, count cap, empty omit, missing-ts fallback. Pre-existing scope.rs `derive(Eq)` + `Scope { … }` literal broke under §3.x's f32 fields — fixed forward (drop Eq, spread `..Scope::default()`).
- [x] 4.2 Outcome glyph wired into the formatter via `outcome_glyph(Option<&str>)` and `decision_glyph(&str)` helpers. SimilarTurn lines now read `{i}. {glyph} {date} — {model} {summary}`; decision lines read `- {glyph} **{id} ({status}{date_suffix})** — {title}`.
