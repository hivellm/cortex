## 3. Consume confidence
- [x] 3.1 DONE: graph lane down-weights edges by confidence. Implemented in `lanes/nexus_graph_lane.rs` (not `search/strategies.rs`) because confidence is an edge property only available AFTER the Cypher runs — `strategies.rs` builds plans before any edge is seen, so weighting there is impossible. Each strategy Cypher now `RETURN`s `r.confidence`/`r.confidence_score` (cells 5/6); `project_row` multiplies the hop score by `confidence_weight` (extracted ×1.0, inferred ×0.7, ambiguous ×0.4; explicit score wins; absent → ×1.0 back-compat).
