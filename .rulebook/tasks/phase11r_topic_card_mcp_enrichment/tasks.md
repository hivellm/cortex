## 2. cortex-topic-cards crate

- [ ] 2.1 New crate `crates/cortex-topic-cards/` added to workspace members. - [ ] 2.2 Prompt template at `crates/cortex-topic-cards/templates/rewrite.md` with slots `{{topic_slug}}`, `{{repo_scope}}`, `{{existing_synthesis}}`, `{{existing_revision}}`, `{{new_evidence_block}}`, `{{superseded_evidence_block}}`, `{{output_contract}}`. Output contract pins `{title, synthesis_markdown, contradictions, open_questions, confidence}` JSON shape. `templates.rs` resolves via `Template::for_action(Action::Rewrite)` and renders via plain `{{key}}` substitution. 3 unit tests pin substitution + fallback (typos surface as literal slots).
- [ ] 2.3 `synthesiser.rs` ships `TopicCardSynthesiser` wrapper around `cortex_consolidator::Summariser` (NOT a new trait — composition over duplication). `rewrite(input: RewriteInput, summariser: &dyn Summariser) -> Result<RewriteOutput, SynthesiserError>`. Output parsing strips ```json``` code fences then deserialises into the contract JSON. `SynthesiserError` reuses `cortex_consolidator::SummariserError` variants. Pricing inherited via Summariser. 5 unit tests pin parse-success, code-fence-stripped, missing-field rejection, cost-passthrough, error-mapping.
- [ ] 2.4 `producer.rs` ships the rewrite pipeline: `produce(input: ProduceInput, summariser: &dyn Summariser) -> Result<ProducedTopicCard, ProducerError>`. Pipeline: render prompt → summariser.summarise → parse → run `validate_produced` (forwards to §1.5 cross-field rules) → build `TopicCardPayload` with `revision = existing.revision + 1` (or 1 if first emit), `events_since_last_rev = 0`, `last_rev_at = now()`, `synthesis_cost_cents` carried from summariser → return `ProducedTopicCard { payload, cost_cents }`. Idempotent topic_card_id via §1.3 derivation. 8 unit tests covering: first-emit revision=1, re-rewrite revision monotonicity, evidence accumulation, code-fence stripping, missing-field rejection, summary-below-floor rejection, idempotent id across runs, cost passthrough.
- [ ] 2.5 `trigger.rs` ships `Trigger::evaluate(card: Option<&TopicCardPayload>, new_event: &Envelope, embedding_distance_fn: &dyn Fn(&Envelope, &str) -> f32) -> TriggerDecision`. Heuristics: rewrite when `events_since_last_rev >= 8` (constant `TRIGGER_EVENTS_THRESHOLD`), OR `embedding_distance < 0.30` (constant `TRIGGER_DISTANCE_THRESHOLD`) AND new_event is Decision/LawViolation/high-impact-outcome, OR `synthesis_age_d >= 14` (constant `TRIGGER_AGE_DAYS`) and any new evidence lands. `TriggerDecision = Rewrite | Hold { reason }` where `reason ∈ {Cooldown, LowImpact, NotRelevant}`. 7 unit tests pin every branch.
- [ ] 2.6 `contradictions.rs` ships `ContradictionScanner::scan(evidence: &[EvidenceRef], hydrate_fn: &dyn Fn(&EvidenceRef) -> HydratedEvidence) -> Vec<Contradiction>`. Three detector classes: `decision_supersession` (any pair where `a.supersedes == b.id` or vice versa; emits Contradiction with status=Open and references both), `law_violation_mismatch` (LawViolation cites a Law version different from latest active), `outcome_divergence` (two consolidations overlapping temporal_span with conflicting outcome_distribution majority). Heuristic only — never blocks rewrite. 9 unit tests covering each class accept/reject + edge cases (single evidence, no contradictions, mixed kinds).
- [ ] 2.7 `orchestrator.rs` ships `Orchestrator::run(card_id_or_none, new_evidence, repo_scope, summariser)` with the same `CostBudget` + `CostLedger` (`grain = "topic_card"`) the consolidator uses. `with_budget(CostBudget)` builder. Auto-promotion to Opus when (a) contradictions.len() ≥ 3 OR (b) any evidence pair triggers `decision_supersession` OR (c) operator passes `--deep`. Budget gate uses conservative per-kind estimate (100 cents Haiku / 4 000 cents Opus). 4 unit tests pin: orchestrator stamps cost into `topic_card` grain bucket, budget-gate refusal, Opus auto-promotion on contradiction-count, operator override.
- [ ] 2.8 `crates/cortex-cli/src/bin/cortex-topic-cards.rs` CLI binary with subcommands `rewrite <topic_slug>`, `scan-now`, `replay --since <ts>`, `nightly --dry-run`. Top-level flags `--api-key` (env `ANTHROPIC_API_KEY`), `--api-url` (env `ANTHROPIC_API_URL`), `--monthly-cents-cap` (default 100_000), `--verbose`, `--deep`. Each subcommand prints a `plan` header before any API call. `nightly --dry-run` works offline. Bin registered in `crates/cortex-cli/Cargo.toml`. 5 clap-surface unit tests.
- [ ] 2.9 Crate-level integration test at `crates/cortex-topic-cards/tests/end_to_end_it.rs`: synthesise a 30-event corpus (mixed Turn/Decision/LawViolation/Consolidation), let the trigger fire 3 rewrites, assert revision monotonicity (1 → 2 → 3), evidence accumulates without duplication, contradictions surfaced when a Decision supersession lands, idempotent topic_card_id across rewrites, cost ledger records under `"topic_card"` grain. ## 4. MCP tools

- [ ] 4.1 `cortex_topic_get(query_or_slug: String, scope: Scope) -> Option<TopicCard>` in `crates/cortex-api/src/mcp.rs`. Slug-exact short-circuit (regex match on `^[a-z0-9-]+$`, then direct read from per-repo collection). - [ ] 4.2 `cortex_topic_drill(topic_card_id: TopicCardId, dimension: DrillDimension)` where `DrillDimension ∈ {Evidence, Contradictions, History, OpenQuestions, Related}`. Evidence path hydrates each item with title + occurred_at via Synap reads. History path returns `Vec<TopicCardRevision>` (id, revision, last_rev_at, synthesis_diff_hash) by walking `parent_event_id` chain. Related path queries Nexus for outgoing `RELATED_TO` edges. 5 unit tests (one per dimension) + 1 IT.
- [ ] 4.3 `cortex_topic_neighbors(topic_card_id: TopicCardId, depth: u8 = 2) -> NeighborGraph`. Cypher query `MATCH (t:TopicCard {id: $id})-[:RELATED_TO|EVIDENCE_OF*1..$depth]-(n) RETURN n LIMIT 64`. Returns subgraph with nodes + edges, clipped at 64 nodes. 3 unit tests (depth=1, depth=2, clip-at-64) + 1 IT.
- [ ] 4.4 `cortex_topic_diff(topic_card_id: TopicCardId, since_rev: u32) -> TopicCardDiff` returning `{from_rev, to_rev, synthesis_diff: String, evidence_added: Vec<EvidenceRef>, evidence_removed: Vec<EvidenceRef>, contradictions_added: Vec<Contradiction>, contradictions_resolved: Vec<Contradiction>}`. `synthesis_diff` uses unified-diff format on the markdown body. 4 unit tests + 1 IT.
- [ ] 4.5 `cortex_synthesize(query: String, scope: Scope, force: bool = false, persist: bool = false) -> ProducedTopicCard`. Operator escape hatch — runs the synthesiser ad-hoc through the orchestrator. When `persist=true`, emits a TopicCard envelope normally; when false, returns the payload without indexing. Counts against `CostBudget` either way. Refuses with `BudgetExhausted` error when over cap. 5 unit tests + 1 IT.
