DECISION: SCIP is a **higher-precision Phase-1 (deterministic-facts) backend**, NOT a new pipeline. GATING KNOWLEDGE for §2: the parser/resolver needs the EXACT `rust-analyzer scip` JSON schema (SCIP `Index`/`Document`/`Occurrence`/`SymbolInformation`, the `symbol_roles` bitfield, the `local …` / `scheme manager pkg ver descriptors` symbol grammar) captured from REAL rust-analyzer output, plus the `Symbol`-node key scheme + same-document-precedence resolution design — these are real design choices best fixed in a focused session (as phase27b's algorithm was), not coded against a from-memory fixture.

## 2. SCIP ingestion (Rust first)
- [x] 2.1 New `graph/scip.rs` module (in cortex-workers per the no-new-crates law). PREMISE CORRECTED with real data: `rust-analyzer scip` emits **protobuf**, not JSON — the §1.1 gating knowledge was captured from REAL rust-analyzer 1.96.0 output (fixture crate → `rust-analyzer scip` → `protoc --decode_raw`; full field map + symbol grammar + gotchas in this task's `design.md`; the real 5KB binary fixture is committed at `tests/fixtures/scip/rust_analyzer_1_96_fixture.scip`). Parser is a minimal hand-rolled protobuf wire reader (~60 lines; no prost/protoc build dependency): `parse_scip_bytes` → `ScipIndex/Document/Occurrence/Range/SymbolInfo`, `symbol_roles` bitfield helper (`& 1`, never `== 1`), packed-varint 3-vs-4-element range decode, Windows backslash path normalization, and the `local N` / `scheme manager pkg[ url|ver] descriptors` symbol grammar (`parse_symbol`/`qualified_name()` — `impl#[Worker]new().` → `Worker::new`).
- [x] 2.2 Two-pass resolver `scip_to_patch`: pass 1 indexes definitions → `:Symbol` nodes keyed `{repo}|rust|{qualified_name}` (matching patch_builder's convention) + `DEFINES` edges from the containing `:Artifact`; pass 2 resolves references (same-document precedence, global fallback) → `CALLS` (fn→fn) / `REFERENCES` edges, all `EdgeConfidence::Extracted` (1.0) with `analyzer="scip"`. Resolution keys on COMPUTED qualified name, not raw symbol string — real fixture data showed rust-analyzer emits `Worker#` for the struct def but bare `impl#[Worker]` for Self-references, two raw strings for one logical entity.
