## 4. Scheduler + dashboard rewire
- [x] 4.1 New in-process supervisor `SweepRegistry { Vec<Box<dyn Sweep>> }` (file `sweep/registry.rs`) — uniform invocation surface that supersedes the per-sweep ad-hoc child-process scheduling for the trait-aware path. `canonical_registry(...)` constructor wires the seven Phase13a sweeps in declaration order. The legacy `retention::scheduler` Runner stays for the operator-tunable `cron_jobs` rows pending Phase B's full process-model migration; the production daemon will switch path during Phase B without revisiting the trait surface.
- [x] 4.2 `SweepRegistry::run_all` writes one `retention_sweeps` row per `Sweep::run` invocation: `start_retention_sweep` (with abandon-grace honoured) → `Sweep::run` → `finish_retention_sweep` carrying the full `SweepReport` serialised as JSON into `tier_transitions_json`. Sweep-internal failures land as `status = failed` rows with `error_message` in the payload; persistence failures short-circuit and return `RegistryError`. IT `crates/cortex-workers/tests/sweep_registry_canonical_it.rs` walks the canonical 7-sweep registry against an in-memory MetadataStore + tempfile archive + tempfile CAS DB + every backend's memory double and asserts exactly 7 `retention_sweeps` rows materialise with parseable `SweepReport` payloads.
- [x] 4.3 `crates/cortex-api/src/dashboard/retention.rs::retention_state` now sources `last_run` + `last_status` from `retention_sweeps` (most-recent row per sweep name via the JSON payload's `name` field, parsed by new `parse_sweep_name` helper) and falls back to `cron_jobs` only for failure-streak (Phase B moves streaks to a sweep-level counter). `ScheduledRun.next_run` reshaped from `String` to `Option<String>` so missing cron rows surface as wire-level `null` instead of a handler-side sentinel. Zero matches for `"never"|"n/a"|"unknown"` in `crates/cortex-api/src/dashboard/**` (verified). CI grep gate added at `.github/workflows/dashboard-grep-gate.yml`. GUI `RetentionScheduledRun.next_run` type widened to `string | null | undefined`; existing render already maps `null`→`"—"`. 7 dashboard unit tests green.
