- [x] 1.2 `derive` already walks ancestors via `repo_from_cwd` (`scope.rs:95-111`): every directory from `cwd` upward is checked for `.git`; on hit it reads `cortex.toml`'s `cortex.id` if present, otherwise falls back to the directory basename via `dir.file_name().to_str()`. Always emits a non-empty `repo` when a `.git` ancestor exists.

## 2. Filter propagation through lanes
- [x] 2.1 `crates/cortex-api/src/strategies.rs::repo_scoped` already runs `req.scope.repo` through `cortex_storage::names::slug_for_repo` and produces the canonical `cortex-{slug}-{family}` index/collection name. Every `KeywordRequest` / `VectorRequest` / `GraphRequest` the strategies build for `pre_change_context`, `decision`, `similar_turns`, `law_review` etc. uses `repo_scoped(req, family)` for its index / collection name and `scope: req.scope.clone()` for the structural filter — so each lane's hits are bounded to the per-project surface even before the lane applies its own filter.
- [x] 2.2 Filter format documented in code: the strategies pin the `cortex-{slug}-{family}` name as the unit of repo isolation (rather than a separate `filter: repo IN […]` clause). Per-project Meili indexes ship the spec-08 settings via the lazy `MeiliFulltextIndexer::ensure_settings` path so `sort: ["ts:desc"]` and `filter: ["kind = X"]` queries succeed; Vectorizer collections follow the same naming so a request scoped to `Vectorizer` only ever contacts `cortex-vectorizer-{code,docs,turns}`. Cypher reads (graph endpoint + decision_detail) interpolate the slug directly into the literal-Cypher form `phase1_graph_writer_nexus_compat` settled on.
- [x] 2.3 Empty `scope.repo` is handled by `repo_scoped`: when the field is `None` or empty the slug falls back to `UNKNOWN_REPO_SLUG` (`unknown`), which produces `cortex-unknown-{family}`. The lane simply returns zero hits against that index — surfacing the missing scope to the caller rather than silently fanning out to every repo. A future "global" mode (filter against every per-project surface) would need an explicit opt-in flag; the current behaviour is honest about the missing scope.
