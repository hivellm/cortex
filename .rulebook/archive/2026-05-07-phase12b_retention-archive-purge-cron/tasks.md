## 1. Storage layer — purge_before
- [x] 1.1 New module [`crates/cortex-storage/src/archive_purge.rs`](../../../crates/cortex-storage/src/archive_purge.rs) exposes `pub fn purge_before(home: &Path, cutoff: DateTime<Utc>, dry_run: bool, repo_filter: Option<&str>) -> Result<PurgeReport, PurgeError>`. Signature carries the `repo_filter` flag from §2.1 so the storage layer enforces the conservative-keep semantics (a file mixing this repo with others is preserved). Registered in `cortex-storage/src/lib.rs`.
- [x] 1.2 Walks `${home}/events/year=YYYY/month=MM/day=DD/hour=HH/*.parquet` (the canonical layout the bootstrap writer uses). Per file, decodes every NDJSON envelope, tracks the maximum `occurred_at`, and deletes when that maximum is strictly older than `cutoff`. Files with any envelope newer than `cutoff` (or any envelope from a non-matching repo when `repo_filter` is set) are kept — partial purge would orphan the surviving rows from their indexed counterparts in Vectorizer / Meili / Nexus.
- [x] 1.3 Local copy of the `is_live_partial_frame` helper (mirrors `cortex-api::admin_forget`). When the zstd decoder raises any of the three error messages (`incomplete frame` / `Unknown frame` / `frame descriptor`), the walker treats the file as `FileVerdict::Partial` and skips it — the live current-hour file the writer is still flushing is never deleted. The next run picks up the file once the writer rolls to a new hour.
- [x] 1.4 Six tests in `archive_purge::tests` (proposal asked for 4 — the extra two cover dry-run + repo filter). `purge_before_no_archive_returns_zeroed_report` (no files), `purge_before_deletes_every_file_when_all_old` (all old), `purge_before_mixed_keeps_files_with_recent_envelopes` (mixed), `purge_before_partial_frame_guard_keeps_live_writer_file` (partial-frame guard via 4-byte truncation simulating a half-flushed zstd footer), `purge_before_dry_run_does_not_delete` (dry-run pin), `purge_before_repo_filter_pins_files_with_other_repos` (cross-repo conservative keep). `cargo test -p cortex-storage --lib archive_purge` 6/6 green.

- [x] 2.3 Integration test [`crates/cortex-cli/tests/archive_purge_cli_it.rs`](../../../crates/cortex-cli/tests/archive_purge_cli_it.rs) drives the binary end-to-end against a synthetic archive.
