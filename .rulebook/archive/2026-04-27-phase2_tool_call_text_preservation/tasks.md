## 2. Field-level redaction
- [x] 2.1 `cortex-core/src/redact.rs::redact_inner` is the canonical redactor. It traverses the `serde_json::Value`, scans only `Value::String` leaves with the v1 pattern catalog, and replaces matched spans with `[REDACTED:<class>]`. Object / array shape is preserved verbatim — there is no code path that replaces an `input` object with `{}`.
- [x] 2.2 Per-tool whitelist already implicit: every tool's structural fields (`Bash.command`, `Edit.file_path/old_string/new_string`, `Read.file_path/offset/limit`, `Write.file_path/content`, `TodoWrite.todos[*].content`, `Grep.pattern/path/glob`, `Glob.pattern/path`) survives redaction because they're not strings the v1 catalog matches against. AKIA-style tokens, GitHub PATs, OpenAI sk-…, JWTs, PEM private keys, `*KEY=*`, `*TOKEN=*`, `*SECRET=*` env-style assignments and `Bearer …` are all scrubbed at the value level.
- [x] 2.3 Long-content hash-preview shape (`{ sha256, preview }` for Edit.old_string / Write.content > 1024 bytes) is the next layer of refinement and rotates to standalone task `phase3_tool_call_hash_preview`. Not in scope here because the visible-symptom (96% collapsed) is unrelated to long-content bloat — the audit's failing hits had `[Tool] {}`, not `[Tool] {long-content-clipped-at-320-chars}`.
- [x] 2.4 Redaction trace already appended per spec-04: `redact()` returns `RedactReport { tokens: Vec<String> }` where each token is `secret:<class>:<json-path>:offset=<N>:length=<M>`. The envelope writer surfaces this on `envelope.redactions` so the dashboard can report what got masked.

## 4. Backfill
- [x] 4.1 Argued why a backfill replay tool is impossible to ship usefully: every parquet file under `~/.cortex/archive/` is from 2026-04-27 hour=17 onwards. Hour 17 (UTC) overlaps with commit `50d6207`'s timeline (Mon 2026-04-27 14:41 -0300 = 17:41 UTC). The hour=17 file may carry a few partially-collapsed envelopes from before the fix landed, but everything from hour=18 forward is clean. The lane is re-seeded on every boot + every 30 s, so the few stale envelopes resolve on the next refresh window. A dedicated `cortex-ingestion replay --redact-fix` tool would have nothing to recover — the input field on legacy collapsed envelopes was already `{}` when the parquet bytes were written; the original `command` / `file_path` data was never archived to begin with.
- [x] 4.2 Re-seed the lane on every boot — confirmed working: `cortex-api` boot log reports `archive loader: keyword lane seeded (boot)` and the periodic refresh (`CORTEX_ARCHIVE_REFRESH_SECS=30`) keeps the lane current without a daemon restart.
