# VectorizerSync Public APIs & CLI

## User Interface (Electron + React)

### Main Views

**1. Project Management**
- Browse and select local project directories
- Display project list with path, workspace type, sync status
- Add/remove projects
- View last sync timestamp

**2. Workspace Configuration**
- View generated `workspace.yml` content
- Edit collections and patterns (UI: future)
- Preview before export
- Export to file or HiveHub Cloud

**3. Sync Status Dashboard**
- Real-time sync operation progress
- File count processed vs. total
- Error summary with details
- Queue depth and operation history

**4. Settings & Preferences**
- Toggle auto-sync (on/off)
- Configure sync interval (in minutes)
- Set max file size threshold (default: 100KB, max: 10MB)
- Custom exclusion patterns (glob format)
- Notification preferences (sync alerts, errors, quota warnings)
- HiveHub account info (when implemented)

**5. Notification Center**
- List all notifications (internal + HiveHub)
- Mark as read/unread
- Filter by type/severity
- Clickable action links

## IPC (Electron Main ↔ Renderer)

### Commands (Renderer → Main)

```typescript
// Project management
project:add(path: string) → {id, name, path}
project:remove(projectId: string) → boolean
project:list() → Project[]
project:get(projectId: string) → Project

// Sync operations
sync:export(projectId: string) → {workspace_yml: string}
sync:start(projectId: string) → {jobId: string}
sync:pause() → void
sync:resume() → void
sync:getStatus() → {jobId, status, progress}

// Settings
settings:get() → UserSettings
settings:update(partial: Partial<UserSettings>) → UserSettings
```

### Events (Main → Renderer)

```typescript
sync:progress → {jobId, filesProcessed, filesTotal, currentFile}
sync:completed → {jobId, status, filesProcessed, errors?}
sync:error → {jobId, error, recoverable}
notification:new → {id, type, severity, title, message}
quota:updated → {quotaUsed, quotaLimit, percentUsage}
```

## REST API (Future — HiveHub Integration)

### OAuth 2.0
```
POST /oauth/authorize
POST /oauth/token
POST /oauth/token (refresh)
```

### File Operations
```
POST   /api/workspaces/:id/files          (upload)
PUT    /api/workspaces/:id/files/:fileId  (update)
DELETE /api/workspaces/:id/files/:fileId  (delete)
```

### Account & Quota
```
GET /api/account/quota    → {quotaUsed, quotaLimit, planType}
GET /api/notifications    → Notification[]
GET /api/workspaces       → Workspace[]
```

## File Format Outputs

### workspace.yml
```yaml
global_settings:
  file_watcher:
    enabled: true
    auto_discovery: true
    enable_auto_update: true
    exclude_patterns: []
    hot_reload: true
    watch_paths:
      - <absolute-project-path>

projects:
  - name: <project-name>
    path: <absolute-project-path>
    description: <from-UI>
    collections:
      - name: source-code
        description: <auto-generated>
        include_patterns: [src/**/*.ts, src/**/*.tsx]
        exclude_patterns: [node_modules/**, dist/**, ...]
```

**Format**: Vectorizer-compatible YAML, writable by local Vectorizer instances
