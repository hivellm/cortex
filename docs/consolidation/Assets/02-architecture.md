# Directory Layout & Categories

## Repository Structure

```
Assets/
├── Logo-HiveLLM-512x512.png          (light variant)
└── Logo-HiveLLM-512x512-dark.png     (dark variant)
```

## Categories

**Single category**: Brand logos only

- **Format**: PNG raster
- **Dimensions**: 512×512 pixels (fixed size)
- **Color space**: Likely RGB with transparency support
- **Variants**: 2 (light and dark)

## No Subdirectories

Files are at repository root. No organizational hierarchy (icons, banners, illustrations, etc.).

## File Naming Convention

- Prefix: `Logo-`
- Project: `HiveLLM-`
- Size: `512x512` (pixels)
- Variant (optional): `-dark` suffix for dark theme variant

**Pattern**: `Logo-<Project>-<Size>[-Variant].png`
