# Assets Repository Overview

## Purpose

The HiveLLM Assets repository is a **static asset store** for branding and visual identity materials.

## Role

- **Brand repository of record** for HiveLLM logos and visual assets
- **Minimal scope**: contains only logo files (PNG format)
- **Read-only use**: referenced by public-facing projects, documentation, and marketing materials

## Current Holdings

- `Logo-HiveLLM-512x512.png` — light/default variant, 512×512px
- `Logo-HiveLLM-512x512-dark.png` — dark/inverted variant, 512×512px

## Not Included

- Full brand guidelines (colors, typography)
- SVG vectors (only raster PNGs currently)
- Design tools/sources (Figma, Adobe files)
- Non-logo imagery

## Status

**Stable, minimal scope.** No active development or versioning tracked in this repository.
